Excel to SQL Generator

Choose spreadsheet columns and generate SELECT and UPDATE statements locally in your browser.

1. Upload spreadsheet

Supported: .xlsx, .xls, .csv. Header detection is automatic. Large files are processed in the browser in batches; no spreadsheet data is uploaded to a backend.

Note: XLSX files must still be parsed in browser memory. For very large datasets, CSV generally uses less memory than XLSX. Performance depends on your device and file size.

Choose a file to begin.

2. Configure SQL

Use a table name you are authorized to reference.
Set to 100,000 or more for large files; available memory and spreadsheet complexity still matter.

SELECT columns

Select the database columns to return. Names come from the Excel header row.

WHERE columns

Select columns here. For every row, its own Excel cell value becomes the WHERE value.

UPDATE columns

Select columns here. For every row, its own Excel cell value becomes the UPDATE value.

Important: UPDATE statements can modify data. This tool only generates text; it never connects to or executes queries against a database. Always review the table, WHERE columns, and generated SQL before running it.

3. Generated SQL

For large outputs, the preview is capped to keep the page responsive. Download the .txt file to get the complete output.

Privacy note: spreadsheet contents are parsed in this browser tab and are not sent to a database or application server. SheetJS is loaded from its official CDN, so an internet connection is needed unless you download and host that library locally.
